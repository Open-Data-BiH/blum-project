# BLum - Banja Luka urban mobility

BLum is an independent open-source initiative that makes public transport and urban
mobility information in Banja Luka easier to find and use.

It responds to timetables, routes, and service notices that are often scattered, hard to
access, or inconsistent. The goal is to give residents one place to quickly find lines,
stops, timetables, and important service changes.

It is currently focused on public transportation, with the goal of gradually covering
other areas of urban mobility.

BHS version: [README.md](README.md)

> BLum is not an official public transport website.

## Run locally

Node.js 22.12 or later is required.

```bash
npm install
npm run dev
```

Run `npm run ci` to validate the project.
